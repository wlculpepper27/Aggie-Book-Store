Aggie Book Store

A Python-based simulation of a university bookstore system, designed to manage books, authors, and inventory items.
This project is ideal for educational purposes, demonstrating object-oriented programming concepts and basic inventory management.


📂 Project Structure

- `AggieBookStore_4.py`: Main script to run the bookstore simulation.
- `Author.py`: Defines the `Author` class, representing book authors.
- `Book.py`: Contains the `Book` class, encapsulating book details.
- `Item.py`: Implements the `Item` class, managing inventory items.
